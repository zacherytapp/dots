# Research

Use a background agent when the harness provides one and concurrent research would help. Otherwise perform the same workflow sequentially in the current agent; lack of subagent support is never a blocker.

1. Investigate the question against primary sources—official documentation, source code, specifications, and first-party APIs. Trace important claims to the source that owns them.
2. Separate verified facts, version-specific behavior, inference, and unresolved uncertainty.
3. Write one concise Markdown report with citations for material claims.
4. Save it where the repository keeps research notes. If no convention exists, choose a sensible project-local location and report it.
